Nova deliberação

Uma planilha → um formulário → um link

1. Adicionar Planejamento Financeiro

Selecione o XLSX, XLS ou CSV recebido. O portal identifica as abas e prepara uma pergunta de votação conforme o formulário institucional de envio.

Prévia no GitHub Pages: os dados ficam somente neste navegador. Nenhum arquivo é enviado ao Supabase e nenhum voto oficial é registrado.

2. Conferir formulário gerado

Confira os dados financeiros extraídos e revise a pergunta já preparada com base no formulário de envio.

Perguntas para votação

A pergunta principal já vem preenchida. O formulário do conselheiro inclui as cinco opções de voto, justificativas condicionais e avaliação final de clareza e dificuldade. Ajuste a pergunta apenas se necessário.

3. Gerar link demonstrativo

Na versão real, o portal salva o PF no Supabase e a PRESCON publica o formulário após a conferência.
